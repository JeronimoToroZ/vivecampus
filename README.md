# ViveCampus

Plataforma de vivienda verificada para estudiantes universitarios foráneos cerca de Uninorte (Mallorquín, Barranquilla). Proyecto de la materia Creación de Empresa.

Equipo: Hellen Arango, Nicole Duque, Isabela Noble, Jerónimo.

## Estructura

- `index.html` — estructura de la página
- `css/styles.css` — estilos
- `js/main.js` — animaciones y lógica general
- `js/buscador.js` — filtros y tarjetas
- `js/calculadora.js` — calculadora de costos
- `data/apartamentos.json` — datos de los apartamentos (datos de ejemplo)
- `img/` — fotos

## Cómo correrlo

Abrir la carpeta en VS Code y usar la extensión Live Server (clic derecho en `index.html` → Open with Live Server).
